# Sarmayacar Quarterly Report Importer

Private Figma plugin for importing the JSON data pack generated by the FundOps
Streamlit `Quarterly Report` tab.

## Setup

1. Open Figma Desktop.
2. Go to `Plugins > Development > Import plugin from manifest...`.
3. Select `figma_quarterly_report_plugin/manifest.json`.
4. Open the quarterly report Figma template.
5. Select the company-page template frame.
6. Run `Sarmayacar Quarterly Report Importer`.
7. Paste the JSON data pack from Streamlit and import.

## Required Template Layer Names

Inside the selected company-page template frame, name text layers with these
exact names where needed:

- `report.quarter`
- `company.name`
- `company.description`
- `company.update_1`
- `company.update_2`
- `company.update_3`
- `company.update_4`
- `notes.disclaimer`

Metric table placeholders:

- `metric_1.label`
- `metric_1.month_1`
- `metric_1.month_2`
- `metric_1.month_3`
- repeat through `metric_7.*`

QoQ placeholders:

- `qoq_1.metric`
- `qoq_1.percent`
- `qoq_1.change`
- repeat through `qoq_6.*`

The plugin duplicates the selected template frame once per included company and
fills any matching text layers. Missing layers are reported as warnings but do
not block page creation.
